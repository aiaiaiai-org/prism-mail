# Security

Do not report vulnerabilities through a public issue.

Use GitHub private vulnerability reporting for this repository when available. Include the affected revision, impact, reproduction details, and any relevant logs with secrets and message contents removed.

Mail bodies, attachments, provider credentials, AI credentials, OAuth tokens, and generated access tokens are sensitive. Do not place them in issues, pull requests, test fixtures, logs, screenshots, or example configuration.
